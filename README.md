# Dan Kibiwott Portfolio

My personal website, built with Next.js, TypeScript, Tailwind CSS, and MDX.

## Local Development

```bash
yarn install
yarn dev
```

## Checks

```bash
yarn typecheck
yarn build
```

## Content

- Project and reading data lives in `lib/constants.ts`.
- Articles live in `app/writing/_articles`.
- Public images live in `public`.
